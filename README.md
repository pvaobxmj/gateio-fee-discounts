## 할인 경로 2: GT로 수수료 결제

GT는 게이트의 자체 토큰이고, 이걸 수수료 결제 수단으로 지정하면 요율이 한 단계 더 내려갑니다. VIP 0 기준 0.1% → 0.09%, 체감상 10% 할인입니다.

설정 위치는 계정 → 수수료 설정 → "GT로 수수료 결제" 토글입니다. 켜두면 수수료를 GT에서 먼저 차감하고, GT 잔액이 부족해지면 자동으로 원래 VIP 요율로 돌아갑니다.

주의할 지점 두 가지.

첫째, 이 할인은 VIP 9까지는 유효하지만 VIP 10부터는 GT 요율과 일반 VIP 요율이 같아집니다. 요율이 가장 낮은 구간에서는 이미 의미가 없어진다는 뜻입니다.

둘째, GT 결제와 포인트 카드(점카드)는 중복 적용되지 않습니다. 그리고 점카드의 스팟 요율은 고정 0.2%로, VIP 0 기본 요율(0.1%)보다 오히려 비쌉니다. 선물 테이커에 한해 0.075% 고정이라는 조건이 붙지만, 스팟 위주로 거래한다면 점카드보다 GT 결제가 낫습니다.

월 거래량 100만 USDT 기준으로 0.1%와 0.09%의 차이는 100 USDT입니다. 한 달에 100 USDT면 커피값이라고 넘길 수도 있지만, 1년이면 1,200 USDT입니다.

GT를 보유해야 한다는 점은 비용이 아니라 리스크로 봐야 합니다. 할인받으려고 GT를 사두면 GT 가격 하락 위험을 같이 떠안는 구조입니다. 할인 금액보다 GT 가격 변동 폭이 클 수 있다는 점은 계산에 넣어두는 게 맞습니다.

## 할인 경로 3: VIP 등급

게이트의 VIP는 VIP 0부터 VIP 16까지 17단계입니다. 승급 경로가 세 개이고, 셋 중 하나만 충족하면 됩니다.

2. **14일 평균 GT 보유량** — 현물 지갑, 레버리지 계좌,理财 상품에 있는 GT까지 포함
3. **VIP 승급 자산가치** — 보유 코인별 가중치를 적용해 계산한 계정 총자산

GT 보유 기준은 공식 안내로 VIP 1이 1,000 GT, VIP 5가 20,000 GT, VIP 9가 200,000 GT 수준입니다. GT 가격이 움직이면 같은 등급에 필요한 달러 금액도 같이 움직입니다. 그리고 등급은 신청 없이 자동으로 갱신됩니다.
